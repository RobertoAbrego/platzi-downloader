# Platzi Downloader

Descarga cursos de Platzi usando Docker + yt-dlp.

## Requisitos

- Docker Desktop

## Estructura

Crear:

cookies/cookies.txt

## Exportar cookies

1. Inicia sesión en Platzi
2. Exporta cookies desde Chrome
3. Convierte a formato Netscape
4. Guarda como:

cookies/cookies.txt

## Agregar URLs

Editar:

urls.txt

## Ejecutar

docker compose build

docker compose up

## Resultado

Los videos aparecerán en:

downloads/
